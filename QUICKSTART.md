# ⚡ CodeSnap - 5-Minute Quick Start

Get started with CodeSnap in 5 minutes or less!

---

## 🚀 Installation (2 minutes)

```bash
# 1. Install dependencies
npm install

# 2. Build
npm run build

# 3. Start
npm start
```

✅ **App is now running!** Look for the tray icon.

---

## 📸 Take Your First Screenshot (30 seconds)

### Method 1: Quick Capture ⚡

**Perfect for instant screenshots!**

1. **Copy some code** (any code!)
   ```javascript
   console.log("Hello, CodeSnap!");
   ```

2. **Press:** `Cmd + Shift + C` (Mac) or `Ctrl + Shift + C` (Windows/Linux)

3. **Boom!** 🎉 Preview window appears

4. **Click "Copy"** → Paste anywhere (Twitter, Slack, etc.)

**Done!** Your first screenshot in 30 seconds.

---

### Method 2: Full Editor 🎨

**Perfect for customization!**

1. **Press:** `Cmd + Shift + L` (Mac) or `Ctrl + Shift + L` (Windows/Linux)

2. **Paste your code** in the big text area

3. **Choose a theme** (try "Dracula" or "Tokyo Night")

4. **Press:** `Cmd + S` (Mac) or `Ctrl + S` (Windows/Linux) to save

**Done!** Custom screenshot saved.

---

## 🎨 Try Different Themes (1 minute)

The editor has **4 tabs**:

1. **Code** - Edit your code, choose language
2. **Style** - 16 themes! Click any to try
3. **Window** - Change background & window style
4. **Export** - Copy or save

**Just click around and watch the live preview update!**

## ⌨️ Essential Shortcuts

| Shortcut | Action |

| `Cmd/Ctrl + Shift + C` | Quick capture |
| `Cmd/Ctrl + Shift + L` | Open editor |
